# Tool UI attribution

The read-only table/chart payload schemas and presentation in this directory are adapted from [assistant-ui/tool-ui](https://github.com/assistant-ui/tool-ui), revision `49a870286facdbf28160cd647f0d337ebdc9b275` (DataTable and Chart).

This is a deliberately reduced adaptation, not an unmodified registry install. It retains schema-validated, source-owned components, uses React 18 and the application's CSS tokens, removes generated actions/styles and unused formatting modes, adds bounded payloads, and uses a lightweight bar chart with a data-table alternative instead of Recharts. No upstream runtime compatibility is implied.
